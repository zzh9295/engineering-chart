# 工程横道图生成器

一款基于 Python + Tkinter 的桌面应用，用于快速创建和管理工程项目进度横道图。支持任务录入、工期自动计算、横道图预览、缩放查看，以及 CSV / 图片 / Excel / JSON 多种格式导出，适合项目经理、工程计划员和需要可视化进度安排的团队使用。

## 主要功能

- 任务清单管理：添加、删除任务，自动计算工期
- 横道图预览：实时渲染带时间轴的项目进度图
- 缩放控制：支持放大、缩小和重置视图
- 数据导出：导出为 CSV、PNG/JPG 图片、Excel 和 JSON
- 示例数据：一键加载示例工程，快速体验功能

## 环境要求

- Python 3.8 或更高版本
- 依赖库：`Pillow`、`openpyxl`

## 安装步骤

1. 克隆或下载项目到本地目录。

2. 安装依赖：

   ```bash
   pip install Pillow openpyxl
   ```

## 启动方式

在项目根目录下执行以下任一命令：

```bash
# 方式一：直接运行入口文件
python run.py

# 方式二：以模块方式运行
python -m gantt_app
```

## 快速使用

1. **填写项目信息**：在顶部输入项目名称和编号。
2. **录入任务**：点击“添加任务”，输入任务名称、开始日期、结束日期，选择任务类型。
3. **生成横道图**：点击“🚀 生成横道图”查看可视化结果。
4. **调整视图**：使用“放大 / 缩小 / 重置”按钮调整显示比例。
5. **导出数据**：点击右侧导出按钮，将项目数据保存为所需格式。
6. **加载示例**：点击“📋 示例数据”可快速查看完整示例工程。

## 项目结构

```
gantt_app/
├── app.py              # 应用控制器
├── config.py           # 主题、尺寸、示例数据等配置
├── models.py           # 数据模型与任务解析
├── ui/                 # UI 组件
│   ├── components.py   # 任务面板与横道图画布
│   └── theme.py        # 主题样式
├── exporters/          # 导出器
│   └── exporters.py    # CSV / 图片 / Excel / JSON 导出
└── utils/              # 工具函数
    └── chart_layout.py # 横道图布局计算
```
