# 工程横道图生成器

一款基于 Python + Tkinter 开发的桌面端工程项目进度管理工具，帮助用户快速录入任务、自动计算工期、可视化生成横道图，并支持多种常用格式导出。

---

## 软件简介

**工程横道图生成器** 专为工程项目进度规划而设计。通过简洁直观的图形界面，用户可以快速维护项目任务清单，系统将自动根据起止日期计算工期，并实时渲染带有时间轴的横道图预览。无论是个人施工项目作业、研发计划，还是其他需要按时间线推进的工程，均可使用本工具进行可视化管理。

### 主要特点

- **零配置开箱即用**：提供独立可执行程序，无需安装 Python 环境即可运行。
- **任务可视化编辑**：添加、删除任务，自动计算工期，实时更新图表。
- **交互式横道图预览**：支持放大、缩小、重置视图，便于查看长期或细节进度。
- **多种导出格式**：一键导出 CSV、PNG/JPG 图片、Excel 和 JSON，方便汇报与归档。
- **示例工程模板**：内置示例数据，帮助新用户快速上手体验完整流程。

## 环境要求

### 方式一：使用独立可执行文件（推荐）

- Windows 7 或更高版本操作系统
- 直接运行 `dist/GanttChartGenerator/GanttChartGenerator.exe`，无需额外安装环境

### 方式二：从源码运行

- Python 3.8 或更高版本
- 依赖库：
  - `Pillow`（图片生成）
  - `openpyxl`（Excel 导出）

## 项目结构

```
gantt_app/
├── app.py              # 应用控制器与主窗口逻辑
├── config.py           # 主题、尺寸、示例数据等配置
├── models.py           # 数据模型与任务解析
├── ui/                 # UI 组件
│   ├── components.py   # 任务面板与横道图画布
│   └── theme.py        # 主题样式
├── exporters/          # 导出器
│   └── exporters.py    # CSV / 图片 / Excel / JSON 导出
└── utils/              # 工具函数
    └── chart_layout.py # 横道图布局计算
```

---

## 注意事项

- 日期格式请统一使用 `YYYY-MM-DD`，例如 `2026-07-26`。
- 导出 Excel 时，如果时间跨度过长超出 Excel 列数限制，软件将给出提示。
- 若从源码运行，请确保已正确安装 `Pillow` 和 `openpyxl`。
